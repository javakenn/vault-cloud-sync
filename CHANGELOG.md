# Changelog

## 0.3.0

First public source release. Includes the Obsidian plugin and a self-hosted Cloudflare backend, an account-aware setup wizard with resumable resource provisioning, independent device configuration packages, bilingual documentation and a privacy disclosure. Plugin responses and saved settings are validated at runtime. The plugin ID remains `ob-collector` for compatibility with the earlier private prototype.

This GitHub release is not an announcement of Community directory approval. Physical iOS/Android installation and large-vault capacity still need user-device validation.
