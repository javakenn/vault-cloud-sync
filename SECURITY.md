# Security reporting

Do not post credentials, notes, device packages or private configuration in issues. For a suspected security issue, use GitHub's private vulnerability reporting for this repository if available. Otherwise open a minimal issue asking for a private contact without including exploit details or user data.

Users control their own Cloudflare account, resources, administrator credential and device tokens. There is no shared author-hosted backend. Rotate affected credentials, revoke compromised devices and review access in your own Cloudflare dashboard. The plugin does not provide end-to-end encryption or remote erasure of downloaded files.
